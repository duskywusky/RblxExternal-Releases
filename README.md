# Dusk downloads

Build 23. Download [Dusk.exe](https://raw.githubusercontent.com/duskywusky/RblxExternal-Releases/main/Dusk.exe).

The single executable contains the app and automatically checks signed updates. Settings live in `%LOCALAPPDATA%\Dusk`. The previous installed app remains available offline.

This is a generated binary distribution; source and signing credentials are private.
